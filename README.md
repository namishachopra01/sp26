# Personal Portfolio Website

A modern and responsive **personal portfolio website** created for Namisha Chopra, currently pursuing B.Tech in Computer Science & Engineering at Lovely Professional University.

The website provides a simple introduction, educational background, areas of learning, and other information through a clean and aesthetic interface.

## Features

- Responsive navigation bar
- Hero introduction section
- About Me section
- Education section
- Areas of Learning section
- Contact section
- Smooth page navigation
- Scroll reveal animations
- Active navigation highlighting
- Responsive mobile navigation menu
- Automatic copyright year

## Technologies Used

- **HTML5** — Provides the structure and content of the portfolio
- **CSS3** — Used for the responsive layout, typography, colors, cards, animations, and overall design
- **JavaScript** — Adds interactive navigation, scroll animations, active section highlighting, and mobile menu functionality

## What I Learned

This project helped me practice building a complete multi-section website, creating responsive layouts, using CSS media queries, implementing JavaScript event listeners and Intersection Observer, and organizing HTML, CSS, and JavaScript into separate files.

## Future Improvements

The portfolio can be expanded in the future by adding personal projects, technical skills, certificates, a resume, GitHub and LinkedIn profiles, contact information, and additional achievements.
